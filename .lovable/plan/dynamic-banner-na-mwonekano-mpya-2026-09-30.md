# Dynamic Banner na mwonekano mpya

## Tutakachojenga
- Kuongeza API za kuangalia, kuwasha, kuzima, na ku-refresh Dynamic SSH Banner kupitia proxy iliyopo.
- Kuongeza kadi ya Dynamic SSH Banner kwenye admin panel yenye status, idadi ya banners, hali ya config, na vitufe vya Enable/Disable/Refresh.
- Baada ya account mpya kutengenezwa kwa mafanikio, kuomba API iwashie/refresh Dynamic Banner bila kuzuia account ikiwa banner API itashindwa.
- Kubadilisha mandhari kuwa nyeupe yenye blue iliyopauka, huku ikihifadhi contrast nzuri na admin controls zinazoonekana wazi.
- Kubadilisha 🌐 ya background iwe mchoro wa duara la dunia unaozunguka mahali pamoja na kubaki nyuma wakati wa scrolling.

## Maelezo ya kiufundi
- Types za banner zitawekwa pamoja na types za API, na hook itatumia TanStack Query pamoja na Sonner iliyopo.
- Tutatumia semantic color tokens kwenye stylesheet badala ya rangi ngumu ndani ya component.
- Tutatumia icons na controls zilizopo kwenye design system; animation itaheshimu reduced-motion.
- Tutakagua admin, account creation, desktop/mobile, na build baada ya mabadiliko.
